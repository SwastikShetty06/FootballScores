# FootballScores

🔗 [Live Application](https://footballscores-swastik.web.app)

## Overview

**FootballScores** is a modern web application for football enthusiasts. It provides up-to-date information about various football leagues, teams, and match scores around the world.

## Features

- **View Top Leagues:** Explore the world's top football leagues and their details.
- **Search Teams:** Easily find team information and recent match results.
- **Responsive Design:** Optimized for all devices with a sleek, modern UI.
- **Animations:** Smooth transitions and interactive elements with Framer Motion.

## Technologies Used

- **React.js**: For building user interfaces
- **Framer Motion**: For animations
- **Axios**: For API requests
- **Bootstrap & React Bootstrap**: For responsive design
- **Firebase Hosting**: For live deployment
